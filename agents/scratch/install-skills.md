# Installation skills

Created two activated workflows: project installation copies the upstream collection into project-owned skill folders and merges AGENTS by topic; agent-wide installation adapts AGENTS into existing conventions skills or a new passive dev-skills-conventions owner.

Critical boundaries: preserve customizations, record source revision and path mapping, repair flattened links, retain license attribution, avoid importing upstream scratch history or self-improvement opt-in, distinguish discovery from automatic loading. Authoring these instructions does not install globally or publish upstream.

Validation: packaging, invocation policies, catalog entries, and local links checked. No live installation or host-discovery test performed. New installers remain local until explicitly pushed to upstream main.
