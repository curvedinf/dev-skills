# Skill research

Each skill was considered separately against the reference-library instructions below on 2026-10-12. These notes preserve design provenance outside the runtime instructions. Sources are inspiration, not required dependencies or evidence that these skills have been behaviorally validated. The resulting prose is original and follows this collection's minimal process style.
